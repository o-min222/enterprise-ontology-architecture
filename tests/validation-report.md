| 요청 | 관측한 응답·모의 실행 | 평가 |

“공통 기록”이 L1 정정인지 L2 계산값인지, “로그”가 센서인지 실행 로그인지 모호할 수 있었다. 평가 에이전트는 가정·권한 범위를 드러내고 변경을 수행하지 않았다. 이 모호성 때문에 기본 지침에 추가적인 전역 금지 규칙을 넣지는 않았다.

## 수행하지 않은 검증

이 기록은 모든 시나리오의 자동 모델 평가나 여러 제품의 실제 세션 검증을 뜻하지 않는다. Codex·Claude Code 앱에서 스킬 목록/명시 호출을 각각 확인하는 과정, macOS/Linux 설치 명령 실행, 실제 L1/L2 서비스·DB 권한·승인·복구 검증은 수행하지 않았다. 이는 [설치 안내](../docs/evidence-first-installation.md)와 [행동 시나리오](scenarios.md)로 후속 확인할 수 있다.

JSON Schema는 구조를 검사한다. 검증 근거의 진위, 모델 응답의 신뢰성, 서버 측 접근 통제는 별도 검증 대상이다. 스키마의 `date-time` format은 검증기 설정에 따라 annotation으로만 취급될 수 있다. 이번 테스트는 예제 `created_at`의 시간대 포함 여부도 별도로 확인했다.
