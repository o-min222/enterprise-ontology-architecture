# Palantir와 이 제안의 관계

Palantir Foundry Ontology는 객체·속성·관계와 Action·Function·권한 등을 연결하는 운영형 플랫폼이다. 이 프로젝트는 **Palantir의 대체 제품**이 아니라 플랫폼에 상관없이 적용할 수 있는 설계·거버넌스 원칙을 제안한다.

| 구분 | Palantir | 이 프로젝트 |
|---|---|---|
| 중심 | 기업 데이터와 운영의 통합 | 공유 의미의 신뢰성과 해석의 독립 |
| 구현 | 통합 플랫폼 | 기존 RDBMS·API 등에서 점진적 시작 |
| 해석 관리 | 설계에 따라 분리 가능 | 기본적으로 별도 보존 |
| Action | 플랫폼 기능으로 지원 | 권한 있는 기존 서비스 API 등 활용 |

**반론: Palantir 위에서도 이 원칙을 구현할 수 있지 않은가?** 맞다. 이 원칙은 Palantir를 사용하는 기업에도 적용 가능하다. 차이는 기능의 가능 여부가 아니라 무엇을 기본 운영 원칙으로 채택하는가에 있다.

참고: [Palantir Foundry Ontology](https://www.palantir.com/docs/foundry/ontology).
