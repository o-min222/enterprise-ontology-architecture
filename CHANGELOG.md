# Changelog

## 0.1.0 — 2026-10-31

Initial packaged preview; not an official directory listing or a hosted service.

- Portable Agent Plugins manifest, Claude Code manifest, repository marketplaces, and OpenAI skill presentation metadata.
- Guided setup companion; standalone core continues to work without configuration.
- Evidence-first reasoning, shared L1/L2, independent interpretation, proportionate verification, provenance, and separate execution authority.
- Optional local Wiki, SQLite, RDF graph storage, migration preview, and cited lexical RAG for the calling AI.
- Bounded environment improvements and efficiency comparisons within existing authority.
- English/Korean guides, Japanese/Chinese quickstarts and catalogs, explicit locale fallback.
- Reproducible source ZIP, package checks, CI workflow, contribution/privacy/security/support guidance.

Earlier implementation history is preserved in Git. Preview versions may change interfaces; review changes and back up project records before updating. No automatic data migrations run on installation.
