# 분석 기록 (필요할 때만 사용)

- 목적·대상·허용 범위:
- 오류 영향과 적절한 검증 수준:
- L1 근거 위치·버전·시점·접근 여부:
- L2 객체·정의·버전 또는 모델 부재:
- 확인한 주장: `information_type` / `verification_status` / 확인 범위·방법·근거
- 타인의 평가: 작성자·목적·기준·근거
- 나의 해석: 근거와 가정
- 충돌·누락·불확실성:
- 권장 조치:
- 실행이 필요한 경우: 대상·영향·기존 권한/승인·추가로 필요한 승인·복구
- 실제 실행 결과: 요청 ID·관측 상태·검증·남은 불확실성 (미실행이면 미실행으로 표시)

민감한 원문·자격증명은 이 공개 양식에 넣지 않는다. 승인과 감사의 상세 증빙은 권한 있는 시스템에서 관리한다.
